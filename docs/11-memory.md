# 11. 記憶／再生構造 — 心的シェアと CEP 被覆

広告や配荷がシェアを動かす前に、ブランドは**思い出されなければならない**。本モジュールは調査票の集計から、心的シェア・カテゴリーエントリーポイント（CEP）被覆・再生率・心的シェアと実購買シェアの差を出す。

## 理論

- **心的シェア** = 当該ブランドの言及 / カテゴリ総言及。非援助想起の回数でも、CEP ごとのリンク票でも同じ正規化が使える。
- **CEP 被覆** = リンク済み CEP 数 / 用意した CEP 数。広い入口を何本持っているか。
- **再生率** = 再想起 / 初回想起。一度思い出した人が次の機会でもう一度思い出すか（反復調査での回答の再現率に相当）。
- **心的−実購買ギャップ** = 心的シェア − 実購買シェア。正なら「買われる以上に思い出されている」。負なら「思い出されていないのにたまたま買われている」（配荷・値引き依存の兆候）。

Dirichlet（[07](./07-dirichlet.md)）が記述するのは定常の購買構造である。本モジュールはその前段——**動かなかった場合の記憶のベースラインではなく、動かす入口の算術**——を担う。

## 前提

- 入力は調査の集計であり、因果推定ではない。
- CEP の辞書（どの入口を聞くか）と業界ベンチマークは非公開資産（[05](./05-boundaries.md)）。
- サンプルが小さいと心的シェアは大きく揺れる。点ではなく、幅で読む（[08](./08-uncertainty.md)）。

## 限界

- 言及回数は「強さ」を測らない。強い一本の記憶と、薄い十本のリンクを区別しない。
- 再生率はパネルが二時点で取れないとき近似になる。
- 診断サービス側の想起スコアは、本モジュールの出口を自己申告の設問に言い換えたもの。スコアの写像そのものは本リポジトリに置かない。

```ts
import { shareOfMind, cepCoverage, mentalPhysicalGap } from "@forecast-manifesto/memory";

shareOfMind(30, 100); // 0.3
mentalPhysicalGap(0.22, 0.18); // +0.04
```
